# Architecture Decision Records

Each ADR records one decision: its context, the options considered, the decision taken, its
consequences, and what would cause it to be revisited.

Status values: **Proposed** (awaiting owner approval) · **Accepted** · **Superseded** · **Rejected**.

All ADRs at revision 0 are **Proposed**. None takes effect until the Phase 0 discovery output is
approved.

| ADR | Decision | Status |
|---|---|---|
| [0001](ADR-0001-shared-drive-ownership.md) | Company-owned Shared Drive, system-owned account | Proposed |
| [0002](ADR-0002-google-sheets-as-mvp-store.md) | Google Sheets as the MVP store, behind a table contract | Proposed |
| [0003](ADR-0003-make-as-orchestrator.md) | Make.com as the orchestration layer | Proposed |
| [0004](ADR-0004-ai-is-advisory-only.md) | AI output is advisory only and never authoritative | Proposed |
| [0005](ADR-0005-central-numbering-service.md) | One central atomic numbering service | Proposed |
| [0006](ADR-0006-approval-binds-to-content-hash.md) | Approvals bind to a content hash | Proposed |
| [0007](ADR-0007-single-document-generation-path.md) | One document generation path (Google Docs → PDF) | Proposed |
| [0008](ADR-0008-defer-accounting-integration.md) | Defer accounting integration to Phase 7 | Proposed |
